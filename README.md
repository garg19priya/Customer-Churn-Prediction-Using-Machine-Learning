# Customer Churn Prediction Using Machine Learning

A Machine Learning and Deep Learning project focused on predicting customer churn using customer demographics, account information, service usage, and behavioral attributes.

The project aims to identify customers who are likely to discontinue a company's services, enabling businesses to take proactive retention measures, minimize customer acquisition losses, and improve customer loyalty.

# Project Objective

To develop a data-driven customer churn prediction model that helps businesses understand customer behavior, anticipate potential customer attrition, and make informed retention decisions. 

# Key Features

Customer Churn Prediction: Predicts whether a customer is likely to leave or continue using a service.

Machine Learning: Implements Logistic Regression for binary classification.

Deep Learning: Uses Artificial Neural Networks (ANN) to identify customer churn patterns.

Data Preprocessing: Handles feature encoding, standardization, and data preparation.

Feature Selection: Applies Pearson correlation to identify relevant predictive attributes.

Model Validation: Uses K-Fold Cross Validation to evaluate model performance.

Performance Evaluation: Analyses model accuracy, precision, recall, F1-score, and confusion matrices.

Customer Retention Strategies: Explores incentives, complaint management, long-term benefits, and personalized service prioritization.
